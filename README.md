# SF — منصة التقييم الأمني

مشروع SF هو مسار تطوير مستقل انطلاقاً من محرك Recon Orchestrator، بهدف بناء برنامج سطح مكتب عربي يعمل على Kali Linux، مع إبقاء المحرك منفصلاً عن الواجهة.

## حالة التطوير

- **فرع التطوير:** `sf-rebuild`
- **المرحلة الحالية:** تأسيس واجهة سطح المكتب العربية.
- **التقنية:** Python + PySide6.
- **الجلسات:** حفظ محلي منظم عبر SQLite.
- **الأدلة:** إدخال ومراجعة سجلات منظمة مع المصدر والثقة وحالة التحقق.
- **التحليل السريع:** فحص محلي بلمسة واحدة لجهاز Kali وواجهاته وبوابته وDNS ومنافذ الاستماع دون ملفات أو اتصال بأجهزة أخرى.
- **الاستيراد المتقدم:** يمكن لاحقاً استيراد Nmap XML محفوظ مسبقاً، لكنه ليس مطلوباً للاستخدام العادي.
- **المستشار:** توصيات تفسيرية ومكتبة أوامر محلية مشروحة ولا تنفذ تلقائياً.
- **التقارير:** تقارير HTML عربية مستقلة للجلسات، تُحدّث في المسار نفسه عند إعادة التوليد.
- **التقارير المستهدفة:** HTML فقط.
- **السلامة:** استيراد محلي للنتائج المحفوظة فقط؛ لا تشغّل الواجهة ماسحات شبكة ولا مراحل المحرك القديم.

## تشغيل نسخة سطح المكتب التجريبية

يتطلب ذلك Python 3.11+ وبيئة افتراضية:

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -e ".[desktop]"
python -m sf_desktop
```

التفاصيل في [دليل SF Desktop](docs/SF_DESKTOP.md).

## ملاحظات مهمة

واجهة SF الحالية تتجه إلى الاستخدام البسيط: جلسة واحدة وتحليل محلي بلمسة واحدة، مع عدم اشتراط ملفات XML. تظهر المراحل في الواجهة للتخطيط فقط ولا تنفّذ فحوصاً. سيتم ربطها تدريجياً بعد مراجعة مسارات التنفيذ، وتوحيد حارس النطاق، وإزالة الفحوص النشطة غير المطلوبة، وإضافة اختبارات تغطي حدود الأمان والأخطاء.

لا تستخدم الأداة إلا على أنظمة أو شبكات تملكها أو لديك تفويض صريح لتقييمها.
